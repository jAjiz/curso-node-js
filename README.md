# 📚 Curso de Node.js

Repositorio con los ejercicios del [Curso de Node.js](https://www.youtube.com/playlist?list=PLUofhDIg_38qm2oPOV-IRTTEKyrVBBaU7) de [midudev](https://midu.dev).

Vengo del desarrollo web con JavaScript, así que este curso me ha servido para expandir mis conocimientos al lado del servidor y entender mejor el ecosistema Node.js.

## 🗂️ Contenido

### Clase 1 - Fundamentos
Módulos nativos de Node.js: `fs`, `http`, `path`, `os`, `process`. Manejo de operaciones asíncronas, sistemas de módulos (ESM vs CommonJS) y creación de servidores HTTP básicos.

### Clase 2 - Express
Introducción a **Express**. Routing, middlewares, manejo de JSON y desarrollo con Nodemon.

### Clase 3 - REST API
API REST completa con **Express**, validación de datos con **Zod** y configuración de **CORS**. Implementación de CRUD, filtros y códigos HTTP correctos.

### Clase 4 - Arquitectura MVC
Refactorización del proyecto anterior aplicando el patrón Modelo-Vista-Controlador. Separación en models, controllers, routes, middlewares y schemas. Uso de ES Modules.

## 🛠️ Stack

- **Express.js** - Framework web para Node.js
- **Zod** - Validación de schemas con tipado seguro
- **CORS** - Middleware para políticas de intercambio de recursos

## 💭 Aprendizajes

Aunque ya tenía experiencia con JavaScript en el frontend, este curso me ha ayudado a:

- Entender cómo funciona Node.js por debajo (event loop, naturaleza asíncrona)
- Trabajar con módulos nativos del core de Node.js
- Construir APIs REST bien estructuradas con Express
- Aplicar patrones de arquitectura MVC en el backend
- Manejar validaciones robustas y políticas de CORS

El contenido está bien organizado y va de lo más básico a conceptos más avanzados. Me sirve como referencia rápida para proyectos futuros con Node.js.
